Why teams pick NebuLens

Nothing new to operate

If you already run Postgres, you already know how to back up, size and secure NebuLens. There is no ClickHouse, Kafka or ZooKeeper to learn.

Up in minutes

One Helm chart deploys the server, the collector and eBPF tracing. Existing OpenTelemetry apps only change their exporter endpoint.

Paid support you can afford

Pro is priced per node from $99 a month, with SSO, roles and an audit log. You do not need an enterprise contract to get a supported self-hosted install.

When another tool is the better choice

We would rather you pick the right tool than switch twice.

  • You ingest far more than a few thousand spans per second. ClickHouse-based tools scale further on one installation.
  • You want a hosted service. SigNoz Cloud, ClickHouse Cloud and Grafana Cloud run it for you; NebuLens is self-hosted only.
  • You need continuous profiling today. Grafana Pyroscope offers it; NebuLens does not yet.
  • You already run the Grafana stack well. Keep it; the cost of switching is real.

Try it next to what you have

Because every tool here speaks OpenTelemetry, you can send the same data to both and compare for two weeks. Add a second exporter to your existing collector:

exporters:
  otlphttp/nebulens:
    endpoint: http://nebulens.observability:4318
service:
  pipelines:
    traces:
      exporters: [otlphttp/current, otlphttp/nebulens]
