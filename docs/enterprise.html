Security controls

The answers to your security questionnaire, built in.

Each control is a setting your platform team owns, not a promise from a vendor.

Data residency

All telemetry is stored in a database inside your environment. Nothing is sent to NebuLens. Retention is configurable per installation.

NEBULENS_RETENTION_HOURS

Sensitive-data redaction

Card numbers (Luhn-checked), SSNs, IBANs, JWTs and API keys are masked at ingest by default. Add email and phone numbers, or your own patterns.

NEBULENS_REDACT=card,ssn,iban,email,jwt,apikey,phone

Encryption in transit

Serve HTTPS directly from the process, or require client certificates (mutual TLS) from collectors and users. Works behind your ingress or service mesh too.

NEBULENS_TLS_CERT · NEBULENS_TLS_CLIENT_CA

Single sign-on

OIDC login with your identity provider. Map groups to roles and restrict sign-in to your email domains.

NEBULENS_OIDC_ISSUER · NEBULENS_OIDC_ADMIN_GROUPS

Separate ingest credentials

Collectors use an ingest-only token that cannot read data. Viewers get a read-only token.

NEBULENS_INGEST_TOKEN · NEBULENS_READ_TOKEN

Audit trail

Every change is recorded with who, what and when. Optionally record reads too, and stream the log to your SIEM over syslog.

NEBULENS_AUDIT_SYSLOG=siem:514/udp

Outbound call safety

Synthetic checks and alert webhooks can never reach cloud metadata services or link-local addresses, and redirects are re-checked.

FAQ

Questions security teams ask us.

Does any telemetry leave our network?

No. NebuLens stores everything in your own database and makes no calls home. The only optional outbound connection is to an AI provider you configure, which can be a model you host yourself. Without one, the assistant uses built-in rule-based analysis.

How is personal data handled?

Common sensitive values are masked when telemetry arrives, before anything is stored. You choose which patterns apply, can add your own, and set how long data is kept.

How is the Pro license checked?

With a license key validated locally. No license server, no usage reporting, and it works in air-gapped sites.

Can we run it without internet access?

Yes. Build the offline bundle on a connected machine, carry it in, and install with the same Helm chart.

What happens to our instrumentation if we leave?

Nothing changes in your code. NebuLens uses standard OpenTelemetry, so you point the same SDKs and collectors at another backend.
